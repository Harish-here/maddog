# Effort primitives

STATUS: foundation, approved by the maintainer on 2026-11-19.

## Definition

Effort is how much work the receiving agent puts into carrying the request
through and making sure the result is right.

## The five primitives

The dispatching agent answers each question about a piece of work at the
moment of handing it over, from the brief alone.

| Primitive | Question |
|---|---|
| Size of the work | How many steps or parts must the receiver get through before it returns? |
| Difficulty | Does the work need working out, or is it routine? |
| Room for hidden error | Can the result look finished and still be wrong? This covers a missed case and a wrong reading of a request that leaves choices open. |
| Outside check | Will anything other than the receiver check the result before it is used? |
| Cost of a miss | What is lost if a wrong result gets used? |

## Changing this document

Rules that turn the answers into an effort level are built on top of these
questions and live elsewhere; they may change. The definition and the
questions change only with the maintainer's approval.
