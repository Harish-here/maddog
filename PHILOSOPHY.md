# Philosophy

This file states the beliefs this repository is designed under — reread it
when a design choice is unclear.
It is written for the author, contributors, and adopters of this repo.

**Intelligence is a budget.** Every task is routed by its shape to the
cheapest hand that covers it. A hard subject does not buy a smart model; an
open decision does.

**Tokens are the new currency. Never pay twice.** A token spent on something
is never spent again on the same thing. A file read once is summarised, a
ruling is filed once and cited, a return is distilled before it reaches the
orchestrator.

**Architect the integrity. Don't just instruct the agent.** A rule that must
hold is built into the structure: the judge holds no edit tools, a hook
denies the write, a guard blocks the shell form. Prose tells an agent what
it must not do. Anything an agent must do is made the only path available.

**Spend your attention on what matters.** There is enough technology to
carry the mechanical work. The human's attention goes to requirements,
decisions, and approvals. Everything else is handed to the technology,
with the evidence coming back for review.

**Harness-neutral core.** The roles, laws, and contracts are plain prose
that any agent runtime could load. Each runtime is one distribution, held
behind a thin adapter of manifests, hooks, and scripts. A design decision
that only works on one runtime is an adapter detail.
