# HOT — always-loaded lines

Laws: every token pays rent every session. Deltas, not norms — the
norm lives in the governing skill or repo. Pointers, not content. A
line where a table tempts.

Exemplar (a memory-index line — pointer, delta, reopen condition):

    - [Retry doctrine](retry-doctrine.md) — backoff is repo law; reopen if the queue moves to at-least-once

Anti-pattern: restating in the index what the linked file already
holds, or tabulating facts any reader of the repo can derive.
