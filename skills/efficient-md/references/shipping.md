# Shipping a file to other users

Read when a file is about to ship to users who do not share this
workspace. This is a step for whoever ships the file, not for its author.

## The rule

A shipped file may cite only what ships with it.

- An unconditional citation of a file that exists only in this session,
  or that does not ship, is replaced by a self-contained statement or by
  a path inside what ships.
- A citation guarded by an existence check is allowed: "plain-english,
  where installed".

Any shorter wording of this rule keeps the guarded-citation allowance, or
the whole rule is left out.

## Example

Before shipping:

```text
Follow the wording rules in the notes from Tuesday's session.
```

After:

```text
Put the outcome first and write full sentences.
```

## Finishing check

Every path and every skill or agent name in the file either ships with
it or sits behind an existence check.
