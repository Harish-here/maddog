# Spec, plan or blueprint

Loaded per task, usually one section at a time, by each agent that
builds from it. Where another skill or the repo sets the format, that
format stands; add only the list of open choices.

## Keep test

Would a builder build something different without this line? Every
line must pass.

## Keep

- Each section a brief can cite has its own heading and names any
  other section it depends on. It has its own finish condition too,
  unless a set format has no place for one.
- A decision is stated as decided. A choice still open goes in one
  list, each with who decides, or "no one named" where the source
  names no one; never in a section as if settled.

## Move out: what leaves the spec

| Content | Where it goes |
|---|---|
| The discussion behind a decision | a filed record, linked |
| How the spec changed over time | version control |
| Options that were rejected | a filed record, linked, when a builder might retry them; otherwise nowhere |

## Finishing check

A builder handed one section by path can build it without opening
another, and nothing undecided reads as decided.
